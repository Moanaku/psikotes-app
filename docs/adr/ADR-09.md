# ADR-09: Distribusi lewat web (GitHub Pages) dan APK, tanpa Play Store

Status: diterima

## Konteks

Keputusan ini diambil selama brainstorming blueprint Simulator Psikotes IT (Oktober 2026). Lihat `../01-prd.md` untuk masalah dan scope.

## Keputusan

Distribusi lewat web (GitHub Pages) dan APK, tanpa Play Store.

## Alasan

Tujuannya portofolio; HR bisa mencoba tanpa install; Rp0.

## Alternatif yang ditolak

Play Store (biaya, review, bukan tujuan).

## Konsekuensi

Fitur plugin yang tidak ada di web harus punya pengganti atau pesan keterbatasan (OCR, penyimpanan aman).
