# ADR-11: Wawancara (F15, F18) dikerjakan paling akhir

Status: diterima

## Konteks

Keputusan ini diambil selama brainstorming blueprint Simulator Psikotes IT (Oktober 2026). Lihat `../01-prd.md` untuk masalah dan scope.

## Keputusan

Wawancara (F15, F18) dikerjakan paling akhir.

## Alasan

Psikotes diuji dan dipakai dulu; wawancara paling bergantung pada layanan luar dan paling berisiko.

## Alternatif yang ditolak

Wawancara di v1.2.

## Konsekuensi

Desain UI wawancara sudah ada, kodenya dimulai di v1.3; UI saja boleh lebih awal (T29).
